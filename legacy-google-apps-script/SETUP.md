# Legacy Google Apps Script — NOT USED BY THE FIREBASE APP

The files in this folder are retained only as historical/reference code for the previous Google Sheet implementation.

The production QA Control Center now uses Firebase Authentication, Cloud Firestore, and Firebase Realtime Database directly from the React app. Do not deploy this Apps Script as a dependency for the Firebase version.

See `FIREBASE-MIGRATION-README.md` in the project root for the current setup and migration steps.
