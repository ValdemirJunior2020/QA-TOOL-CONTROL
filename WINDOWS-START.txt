WINDOWS LOCAL START — FIREBASE VERSION

1. Open PowerShell in this folder.
2. Run: npm install
3. Run: npm run dev
4. Open: http://localhost:5173

Only the React/Vite dev server runs locally.
There is no local Node API and no Netlify Function.

For Google login on localhost, localhost must be allowed by Firebase Authentication. Firebase normally includes localhost for development projects; verify it under Authentication -> Settings -> Authorized domains if sign-in is blocked.
