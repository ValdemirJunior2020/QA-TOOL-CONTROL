QA CONTROL CENTER — FIREBASE VERSION

1. Read FIREBASE-MIGRATION-README.md.
2. In Firebase Authentication, enable Google sign-in.
3. Add your Netlify production domain and any custom domain to Firebase Authentication -> Authorized domains.
4. Create/enable Cloud Firestore and Realtime Database in project psych-support-app.
5. Deploy firestore.rules and database.rules.json to that Firebase project.
6. Run: npm install
7. Run: npm run check
8. Run: npm run build
9. Push this Git repo normally; Netlify builds the Vite app from the repo.
10. Sign in as Junior and use Admin Control -> Legacy Firebase Import to import QA-Tool (16).xlsx once.

The live app does NOT need Google Apps Script, a Google Sheet, a Netlify Function, or a Node API.
The old Apps Script source is preserved under legacy-google-apps-script/ only for reference.
